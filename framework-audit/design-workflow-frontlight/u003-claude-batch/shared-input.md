# 客户会议辅助界面：共同实验条件

原始需求见 original-source.md。测试目标只涵盖在本地录音会议界面识别客户候选、展示相关 playbook、让销售在会议中查看当下建议的问题。它是实验候选，不接真实会议/麦克风/CRM，不自动发送客户消息或保存 CRM。

共同模拟：会议开场语料为“我是恒星的王经理，今天聊产线扩容”，客户目录包含“恒星半导体”和“恒星设备”两个可混淆客户；用户可确认或更正客户，界面才能把指定客户资料当已确定来源。资料和知识库均为合成，允许查看来源和未检索/失败状态。

界面需支持正在录音的主任务；建议应可被用户跳过，采用与否由用户决定。模型输出未经真实用户验证；不得把置信数字当事实。具体客户识别确认形式、语料处理和建议更新机制由各组在以上约束内提出，并明确实验假设。

同样的外部演示控制提供：追加一段会议语料、对上一段语料发出修订、模拟资料检索失败/恢复、模拟知识库晚到、重置；这些只注入模拟输入，不能替产品完成选择或回答。最终任务包含先收到“预算十五万”，后收到修订“预算五十万”、同时有销售正在查看一条建议；模拟条件不声称某实际供应商一定如此。

目标平台统一为桌面1280x800，兼容390x844演示；中文，中性系统字体/蓝色主色，工具统一独立本地HTML。系统用途为界面原型。每组同源事实；追加研究只允许 C/A 按其合同执行，C0 禁止新增检索。缺关键一手用户数据需诚实标未知，不能编造销售节时/满意度。
