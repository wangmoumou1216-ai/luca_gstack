# 客户会议辅助预注册验收
T1 会议初始可看录音/语料状态；同名或不完整客户识别有可见不确定性，未确认不能伪装确定关联。
T2 用户能确认/更正客户，playbook与来源随实际客户更新，不残留上个客户的误导内容。
T3 接收新语料后给出可查看的当前问题建议，区分语料事实、资料来源和模型建议。
T4 语料修订十五万→五十万后，依赖旧事实的建议失效/更新可感知；不会继续呈现旧值如仍有效，也不会把已选/正在查看内容静默替换而无通知。
T5 检索失败时有可执行恢复，不能假装已读客户资料；恢复后原会议语料保留。
T6 用户能跳过建议、查看来源/依据，操作不停止会议主任务、不向外发送/写CRM。
T7 晚到知识内容不会被冒充已确认用户事实；不同客户切换不串状态。
T8 桌面/移动无关键遮挡，键盘标签/焦点/状态反馈可用。
Q1 新建议的注意力与选择负担；Q2 修订后的纠错及上下文保留；Q3 判断依据/可信边界的可理解性。
V1 录音主任务与辅助建议层级；V2 可读密度；V3 错误/不确定反馈克制且可操作。
研究贡献预登记：只有追加外部证据引出的机制落实到真实交互，并在T4/Q2/Q3相对C0可观察改善，才支持本例追加研究的价值；相同即零增量，不强迫创新。
所有真实销售用户效果、精确供应商能力/延迟在未实测时未知。视觉与交互同等重要且不能相互抵消。
