# 第二部分 动态调配方案（峰值三明治 + ARR）

## 2.1 需求钦定（luca 14:07-15:11 原话要点）

1. Codex CLI，默认 5.6-sol，重要场景要更高模型输出
2. 模型动态升级，默认模型会变——锚点制，向上向下兼容
3. **只做模型，不做 effort**
4. 红队、专家会审、计划模式 → peak；深度研究不需要
5. 触发者含 agent："开始计划和结果验证需要高模型"

## 2.2 核心模式：峰值三明治（多峰循环）

```
计划(peak) → 执行(anchor) → 验证(peak) ⟲（否决→重规划(peak)→再执行→再验证）
```

= fable_whitelist P0/P1/P2 在 Codex 侧的补全投影（F3 的修复）。

## 2.3 两角色制

| 角色 | 解析规则 | 当前实例 |
|---|---|---|
| **anchor** | config 顶层 `model =` 行（luca 随时改，唯一 truth） | gpt-5.6-sol |
| **peak** | catalog `priority` 最小值（家族顶部） | gpt-6-astra (p0, ctx 1.05M) |

## 2.4 ARR 锚点动态兼容（向上向下）

```
gap = priority(anchor) − priority(peak)
gap=0    顶锚型 T —— peak=anchor 退化态（验证不对称物理失效，知情确认）
0<gap≤2  常规型 N —— 默认态零动作（当前 gap=1）
gap>2    深降型 D —— 三动作：anchor ctx 校验 / 高峰产出可下移 peak / 矩阵零改动
断言：ctx(P) ≥ ctx(A)；ctx(A) ≥ 常用会话长度
```

四径全覆盖：**上移**退化知情 ｜ **下移**矩阵零改动 ｜ **顶部换代** peak 行 1 行 ｜ **新模型入 catalog** 自动定型。

一行自检（已实测：anchor=gpt-5.6-sol peak=gpt-6-astra gap=1 → 常规N ✓）：

```bash
python3 -c "
import json,re; c={m['slug']:m for m in json.load(open('$HOME/.codex/cockpit-model-catalog.json'))['models']}
a=re.search(r'^model\s*=\s*\"([^\"]+)\"',open('$HOME/.codex/config.toml').read()).group(1)
p=min(c,key=lambda s:c[s].get('priority',9999)); g=c[a].get('priority',9999)-c[p]['priority']
print(f'anchor={a} peak={p} gap={g} →', '顶锚T' if g==0 else '常规N' if g<=2 else '深降D')
print('ctx断言:', c[p]['context_window']>=c[a]['context_window'])"
```
