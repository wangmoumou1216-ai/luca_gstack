## 1. 为什么 v1.0（P2 日落条款）被自己推翻

主审提出异议：**P2 的治理成本大于标的本身**——为了一个 1.8MB 的画图工具，向 SSOT 路由表写 sunset 条款、双锚安装、30 天后跑一次日落裁决，这套机器比它服务的对象重。该异议按规矩重新提交会审，结果异议成立：

> 会审裁决：「比例原则成立。P2 在『登记 + 锚定』项未越红线，**在『自动裁决机器』一项确越红线**。」

## 2. 决策台账（每个候选的下场）

| 候选 | 主张 | 裁决 | 决定性理由 |
|---|---|---|---|
| **P1** | 直接登记为一级 skill | ✗ 否决 | 需求未证即重承诺，违反「使用即留任」 |
| **P2**（v1.0） | 路由 w7 + 30 天日落 + 到期自动裁决 | ✗ 已自我推翻 | 自动裁决机器治理超重；比例失当 |
| **P3** | 不采纳，自建迷你管线 | ✗ 否决 | 不占 enforced 缝隙必休眠；且届时仍答不出「是否真用图」 |
| **A** | 零登记，先跑 3 张真图 | △ 部分成立 | 试炼成立，但「图差就卸」靠人记 = advisory = 永不发生；偏向隐蔽留任无锚安装，**比 P2 更隐蔽** |
| **P4** | 在高频 skill 加 blocking gate 强制评估出图 | ✗ 否决 | 见下节量化：换汤不换药，且更贵 |
| **P5（握手稿）** | 现有清单加一行勾选 + 台账一行 + 自动退役开关 | ✓ **采纳** | 零边际成本、保持 enforced、带默认动作 |

### P4 为什么被杀掉（红队量化，这是本次最硬的一刀）

把「涉及结构就评估是否出图」做成 blocking gate 挂到高频 skill：

- 每日触发评估 ≈ **12.5 次**，其中真正出图 ≈ **0.5 次/日**（出图率 ≈4%）
- 每次强制评估 ≈ +400 token → 空转 ≈ **4.8K token/日 ≈ 144K token/月，其中 98% 是纯 waste**
- 本质判定：「触发率高、行动率低」的 blocking 规则，与被退役的 advisory 规则**无区别，只是更贵**——换汤不换药

## 3. 握手方案正文

### 第 1 步 · 今日取证（零触面，即可执行）

用三个**真实任务**跑三张真图，建立心智锚 + 质量证据：

| # | 图 | 类型 | 价值检验点 |
|---|---|---|---|
| 1 | 锚点制动念调配机制（计划/执行/验证三明治 + peak/anchor 切换） | workflow / lifecycle | 治理机制能否一张图讲清 |
| 2 | route-guard 五级链路判定（Gate → Plan Agent → MULTI/SINGLE → STOP） | workflow | 五级判定的分流条件能否一图说清 |
| 3 | 任选下游项目：code-recon → 系统图 → handoff | architecture | 贯穿 brownfield 到交接的完整链路 |

判定不看"好不好看"，看三条：**能否替代 md 里的三段文字**、**审查者会不会误读**、**是否愿意把它写进 docs/ 并在别的 md 里引用**。

### 第 2 步 · 若留任，最低 primitives（**全部共 3 行**）

| # | 动作 | 位置 | 性质 |
|---|---|---|---|
| 1 | 定稿自检清单加**一行勾选**：「含架构/组件/时序结构？☐是 → 建议 archify 出图」 | `tech-spec` SKILL.md 可改区（该清单**原本就被加载**，边际成本=0） | 零边际 × 已加载 ≠ advisory |
| 2 | 台账一行：`install_path` + `pinned_sha` + `watch_sha` | `installed-pins.yaml` | **唯一 enforced 锁**——防上游静默漂移，接 watcher |
| 3 | 登记一行：场景 / 挂载点 / 护栏 | `external-skills/INTEGRATION-MAP.md` | 治理留痕 |

配套项（非独立 primitives）：
- `vetting-registry.yaml` 一行审计记录
- 每会话最多建议出图 **1 次**（防唠叨）
- **自杀开关**：连续 30 次 tech-spec 判定 ☐否 → 自动退役并卸载（默认动作自动发生，不是"再讨论一次"）

### 第 3 步 · 明令不做的三件事

1. **不登记独立路由词条**——图表请求在本框架历史零自然流量，登记 = 下一个永不匹配的休眠词条（与当年退役的三条规则同构）
2. **不加 blocking gate**——月度 144K token 空转，且实质上仍是纸面规则
3. **不要日落机器**——治理装备超过标的价值

## 4. 安装与护栏（留任时才执行）

```bash
# 固定分发（拒 npx：无受控 checkout 会使 watcher 失明）
SHA=72c750bb070d95171dbb2244e5b62b1b7da69c12
curl -sL "https://raw.githubusercontent.com/tt-a1i/archify/main/archify.zip" -o /tmp/archify.zip
# sha256 须 = d2296515b0091fb8f00580ea9e0b665d91ca5839fde651abe3ecd57a3ca178ec

unzip -q /tmp/archify.zip -d /tmp/archify_extract

```
