# Framework maintenance contract

Load this file for lucagstack framework evolution, governance, self-maintenance, or benchmark work.

Framework/meta work stays `NO_PIN`: do not switch to a downstream project, read shared project aliases, or write project workflow state. The `framework/` template directory remains read-only.

Use the framework-evolution flow before research skills. Choose scout or benchmark mode from the evolution runbooks; research is an evidence phase inside that flow, not a substitute for it. Preserve stable IDs and governed memory promotion. A new durable rule is proposed through the candidate/review pipeline rather than written directly into root context.

Framework work is a maintenance cost. Prefer a change that responds to observed failure, regression, or verified opportunity; batch speculative governance. This is a value check, not a hard quota and never excuses leaving a known safety or correctness failure unfixed.

For any framework mutation, verify Claude and Codex trigger, execution, degradation, and tests separately. No single-harness success can close the change. Do not publish until the repository gate, behaviour/mutation evidence appropriate to the change, and independent review all close.
