# CRM 业务 Profile

CRM（纷享销客）是可选业务语境。用户任务明确涉及 CRM 业务、对象或专项 UX 评审时，
按需读取本文件；仅引用 `framework/` 页面或执行只读保护判定不激活业务与视觉约束。

## 业务与视觉的所有权

- CRM 对象使用稳定 ID；业务术语、权限、对象关系来自已验证的当前项目。
- UX 业务专项仍由 `ux-audit/specialists/module-c-crm.md` 管理；只有用户选择该模块时读取。
- 视觉值与技术实现来自当前项目明确提供的规范，或由用户在 OD / Claude Design 中配置。
  CRM 名称本身不要求本地品牌 token、颜色次数、字体、母版或技术组件映射。
- 页面库仅提供经确认的结构和位置参考；需要采用时按 `runtime/page-context.md` 的唯一合同处理。

## 读取边界

仅做路由或母版保护规则判定到本文件即止，不继续读取设计资产。实际设计/实现按所选 skill 的输入合同读取明确来源。
缺少必需输入（例如必需的需求/状态或 page_interaction_mapping）时停止并索取该项；不猜缺失文件，不扩大项目作用域。
本地 token、母版和技术组件映射不是隐含必需输入。`framework/` 磁盘资产继续只读；缺外部视觉规范不妨碍一般 UX 评审，
但不能据此声称符合某套未取得的规范。
