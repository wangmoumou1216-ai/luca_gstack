# Authorized ADR format

Only read this branch after the existing extraction-bar offer gate and an explicit
record request identify an authorized exact ADR artifact. No default directory is created.

```md
# {Short decision title}

{One to three sentences: context, accepted decision, alternatives and why.}
```

Preserve the owner's existing numbering and location; never renumber existing IDs.
Optional status, rejected options or consequences belong only when they add information.
If a new ADR path/number requires a human choice or scope not granted, return a proposal.
The offer criteria remain solely in extraction-bar.md, not a second local doctrine.
