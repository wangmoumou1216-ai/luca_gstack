# Continuous motion — 抓取、反向与取消的连续性

仅在本次实际已有或明确要求 drag/swipe、运动中抓取、快速反向/中断时，
于相关实现前完整读取；普通静态状态切换不触发。本文件拥有呈现值与速度续接方法，
产品边界、提交/取消结果及真实阈值仍由当前来源拥有。

## 分开逻辑目标与当前呈现

记录产品逻辑状态、目标值、实时呈现值和当前运动实例。重新抓取或反向时，先读取当前屏幕
值或已有 animator 的 presentation value，再暂停/取消旧驱动并固定该值，最后从这里续接。
不能从旧起点或未到达的目标开始，也不能让两个实例同时写同一属性。
CSS transition、WAAPI、JS 或已有 spring 是否能满足此过程由实际运行判断，不按机制名称一刀切。

## 手势链

1. **抓取。** 绑定当前 `pointerId` 和真实 grab offset；按既有触发语义区分点击、滚动和拖动。
   在手势确立且捕获适用时使用 pointer capture，并处理 `pointercancel`/`lostpointercapture`。
   第二个触点不能替换当前点导致跳变；多指能力只有实际来源要求时加入。
2. **跟随。** 坐标使用一致单位与轴，保留抓取偏移；更新当前呈现而非预先提交业务结果。
   收集近期位置/单调时间样本，释放时用有符号速度，避免把全过程平均速率当最后瞬间方向。
   每帧只保留当前有效驱动；布局读取与写入按实际性能症状检查。
3. **释放。** 从真实源边界/取消或提交规则选择结果。距离、速度、投影与 snap point 可以实现
   已有规则，不得凭作者示例新增关闭、删除或确认阈值。API 速度单位及归一化要按实际版本核；
   剩余距离为零或时间样本不足时显式处理，不除零、不合成高速 flick。
4. **续接。** 既有机制支持速度继承时传当前速度；反向更换目标时避免位置跳变并观察速度接缝。
   不支持源要求的连续性则改最小实现或返回能力缺口，不用“已经 spring”自证。
5. **边界与取消。** 允许的边界阻尼/回弹只调呈现；产品值仍限制在源规定范围。
   cancel、失焦、捕获丢失或组件退出都收回当前实例、timer 与帧回调，按来源回到明确结果。

控制表面与页面滚动的轴归属按实际输入能力声明，保留可滚动路径和键盘等价操作。
reduced-motion 可即时收敛到真实逻辑状态，或使用不依赖大幅位移的反馈；不为连续性强迫保留弹跳。
若取消会改变业务副作用，先返回实际设计源；本方法不扩大该权限。

## 过程验证

用同一候选重放：启动→未到终点时反向→再次反向；抓取已移动对象并拖动；释放后再抓取；
跨边界后返回；适用时 pointercancel/捕获丢失/第二触点/退出，及 reduced-motion。
记录输入时间、当前值、接续首值、后续样本、逻辑结果与恢复；观察连续过程而非只拍终态。
位置是否跳回旧端点、是否锁输入、旧回调是否改错结果都是可反驳检查。
真实触感/设备相关声明要有相应设备证据；缺设备只将所依赖声明标 UNKNOWN。

完成：本次所有相关过程从当前呈现续接，边界/取消/终态符合源，副作用与资源收敛可验证。
不强制 Apple 字体、玻璃外观、动画库、固定 damping/response 或通用提交阈值。
