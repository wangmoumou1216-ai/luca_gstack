# UX Research — Report Template

> Loaded by ux-research skill at Phase 4. Do NOT load before Phase 4.
> When `research_depth = moderate`: report detail level = summary findings per dimension (not full detail).

focused 按 `../../deepresearch/references/focused-research.md`：在既有报告头记录真实模式、
原始任务/来源版本、确认取舍、1名研究者及独立审查、实际检索/读取项数。沿用下列章节，
矩阵用证据来源/反证/适用理由替代 D1–D6 投票列，详细发现按 1–3 个实际问题组织；
不要求段数/维度/发现下限。非 AI 的专项审查/可行性写有源 N/A，不新增 AI 研究。
「对设计的信号意义」与「边界条件」说明原任务 → 证据及限制 → 会影响什么取舍，
展开0–3项重要影响（成熟任务可零项），保留全部关键风险。合法结果为改变决定、确认原决定/
排除风险、无当前可用信息；不把后两者写成界面已改善，不把研究信号直接写成用户要求。
零问题时按共享 owner 的 applicability-only 完成分支填既有字段：零研究者、无 findings、
置信度 N/A、真实独立适用性审查；不虚构「已验证范式」或「被否定方向」。
下方“6个并行维度”等为 legacy 占位值；focused 必须替换为真实方法，不伪称执行。
